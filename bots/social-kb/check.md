# 社媒分析 Bot：装好后的验收

按顺序做，每一步都过了才算装好。

1. **演练**（不花钱）：`python3 tests/test_dry_run.py` 全部 OK。
2. **Key 能用**（免费）：`python3 lib/aisa/aisa_cli.py balance` 返回余额，不是 401。
3. **问价**（不花钱）：`python3 lib/aisa/aisa_cli.py run --quote web_page url=https://example.com` 能返回报价。
4. **真跑一条**：发一条你自己的推文或公开网页链接，确认：
   - `inbox/` 里多了一个 JSON，`text` 不是空的
   - `kb/<主题>.md` 里多了一条，带原链接
   - 再发同一个链接，Bot 回复「已经收过」
5. **故意给一条打不开的链接**（比如私密账号），确认 Bot 如实说拿不到，而不是编一段总结。
6. 周报例程建好，手动触发一次，确认格式对。
7. **抖音评论区**（装了这个模块才做）：找一条评论少（一两百条以内）的抖音视频抓一次，`评论全文.md` 里的条数和视频显示的评论数基本一致；中途出现验证码时，Bot 停下来叫你，而不是自己去点。
