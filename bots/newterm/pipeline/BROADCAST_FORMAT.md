# 播报版式（2026-10-25 起，手机优先）

## 开场（最多 2 行）
```
【每日新词播报｜M月D日 早/中/晚】
新增 N：新词 a · 新写法 b · 再推 c · TikTok正式 d · TikTok早期 e · Reddit f · CapCut g · PH h · GitHub i · 付费导航/老词新站 … · 大站 j
```
- 没有的段直接省略（不要写「0」堆砌也可以，计数里带 0 亦可，择一保持一致：有内容才写段名）。
- 禁止写：批次号、过滤口径、预跑 DONE 状态、长方法论文。

## 分节与空行
- 节标题单独一行：`一、新词`
- **节与节之间空一行**
- **每个编号词之前空一行**（词与词不粘在一起）
- 空节：节标题下一行只写 `无`，不解释

## 单个词（正式新词 / TikTok 正式 / 一手源）
```
**1. clover rpg**

- 热度：GPTs × 2.9
- 走势：上升（有才写）
- 来源：哥飞 · 约 10/23 爆发
- 别称：clover rpg roblox（与标题不同才写）
- 是做什么的：一句话说清是什么。下一句写搜的人想找什么。
- 竞品网站：…（有才写）
- 哥飞：值得做 · …（哥飞词才写）
- 推过记录：…（再推/新写法才写；第一次可省略或写「第一次出现」）
- 风险：…（有才写）
```
- **删掉** `- 新词：同名`
- **删掉** 单独的「出现时间」行 → 并进「来源」
- 「主流写法」改名「别称」，且仅当与标题不同
- 热度数字可读即可（× 2.896 → × 2.9 可接受，保留原值也行）
- 「是做什么的」最多两句；不要用分号串成一段墙

## 新写法（更短）
```
**6. roblox the hollow**

- 热度：GPTs × 6.6
- 来源：哥飞
- 推过记录：10/22 the hollow roblox；10/24 the hollow roblox event
- 是做什么的：同一话题的词序新写法。搜的人仍要活动攻略/任务清单。
```

## GitHub Trending（一手）
同正式词；来源写「GitHub Trending」；热度可写未测 Trends。可放第五节，也可并入一、新词（与 GitHub 高星库区分 src）。

## TikTok 早期观察
同正式词字段，但热度可写「约 0」或「未过 ×0.05」；必写第一次出现语境。

## 第七节 过线但没推
```
七、过线但没推

**哥飞**
- 理由：词1、词2
- 另一理由：词3

**自有源**
- …
```
- 按来源加粗小标题；列表一行一条；同类合并

## 付费导航 / 老词新站（一手源）
- 付费导航新上架：不看 Trends；报工具展示名（不是导航域名本身）。
- **老词新站**（需求/能力优先；`oldword_newsites` = 仅 demand）：
  - 导航 newly listed 且产品域/名对准监控池老词（约 ≥2025-05 起热；壳站/关键词站）。
  - 优先报需求词/能力场景（image to video、vocal remover、upscale、background remove、summarize youtube、ai clothes…）。
  - 有则在「付费导航」下设小标题 **老词新站**；无则写 `无`。
  - 字段：工具名、对准老词、产品域线索、导航来源 URL。
  - 只发现、不提交付费；有命中时交接出海站点运营（**主送 demand**）。
  - **不要**用日搜≥3300 毙这类发现。
- **模型壳站（辅）**（`oldword_newsites_model`）：veo/kling/seedance/flux/nano banana 等模型名+版本壳。
  - **有才写**小标题；无则省略。交接时可附带并注明辅/模型壳。
  - 纯品牌域串（Headoffis、Soar90 类）不进主列表。

## 禁止
- 表格
- 用「／」把多字段挤同一行
- 开场方法论长文
- 词与词之间无空行
